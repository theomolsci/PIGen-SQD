The file "PIGen_SQD_data_mbpt_rbm_rank4_sqd_PES_N2_631g_shots_1000000_.pkl" contains all the data associated with PIGen-SQD for potential energy surface of N2 in 6-31G basis. The R_eq is taken to be 1A in this case for convenience. Here, 2 core orbitals are frozen, resulting in 16 spatial orbitals and 10 electrons. Run the read_data_from_pkl.py to print the PIGen-SQD data.

The file "sampler_result_N2_631g_2.0_ibm_marrakesh_shots_1000000.json" contain the Hardware sampler data from IBM_Marrakesh QPU.
